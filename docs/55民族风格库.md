# 55民族风格库

统一的是认可的古典民艺印刷气质，区别来自有范围的文化锚点、字骨、主工艺、主次和色彩。每一条都是创作路线，不能代表民族全体成员或构成文化鉴定。

## 01 蒙古族｜苍穹毡艺

文化范围：内蒙古及相关草原生活语境。

主锚点：蒙古包毡面与木骨结构。
辅助元素：低草原地平线、毡绣卷纹、准确马头琴局部。
默认祝福：山河无恙。用户输入优先，不擅自改词或简繁。
其他可选祝福：八方来财、吉星高照、前程似锦、福满草原。

## 基准方案

字骨：粗笔榜书。主工艺：纸本套印。
构图：山河承字。
标题布局：错落通栏；字数不适合时选择合法布局，不能改动原词来适配。

## 同一审美中的变化

字骨候选：粗笔榜书、清俊行书、隶意票券、金石碑意。
主工艺候选：纸本套印、织毯绒面、皮革烙印、纸本墨色。
构图候选：山河承字、锦纹护字、花叶成境。
字图关系：主字完整可读，所选工艺的线条在标题外缘呼应；不把纹样替换为用户未输入的字。

色谱按创作分工，不把一种颜色定义为某民族唯一的固有颜色：
- 浅纸深字：底#EDE4CF、字#263B35、副#64918D、点#BB963F；浅纸底中深色书法，彩纹控制在主场边侧。
- 深色明字：底#263B35、字#EDE4CF、副#64918D、点#BB963F；深底托出亮字，纹样以细线和局部彩色浮现。
- 主色成境：底#64918D、字#EDE4CF、副#263B35、点#BB963F；工艺色作主底，主字保持清楚明度差；金色只作平薄印色，不出现镜头炫光。

底材：淡纸或浅绢上有低对比细纹，清楚字腔不积污渍；深绢或深色印纸，材质同色可见，主字区域平静；所选主色的平面印色与细织理，色区有层次不叠万能噪点。

## 文化核查

不混用哈萨克鹰猎或藏式经幡；马头琴琴弦和琴轴须依据实物。
当前记录是有范围的设计路线，不宣称覆盖该民族全部支系、审美或信仰。；具体纹样、器物形制、服饰必须另找实物或社区资料，不从人物面貌推断民族。

研究关键词：蒙古族 织毯绒面 非遗 博物馆；蒙古族 蒙古包毡面与木骨结构 实物。
证据状态：研究索引＋保守创作锚点；未做全体社区专家鉴定。名录仅核对民族名称；工艺与地区为待核验研究关键词，不能用名录充当专属纹样证据。

## 同一审美中的变化

字骨候选：粗笔榜书、清俊行书、隶意票券、金石碑意。
主工艺候选：木刻版画、棉线织染、纸本套印、纸本墨色。
构图候选：圆纹回响、锦纹护字、花叶成境。
字图关系：主字完整可读，所选工艺的线条在标题外缘呼应；不把纹样替换为用户未输入的字。

色谱按创作分工，不把一种颜色定义为某民族唯一的固有颜色：
- 浅纸深字：底#EFE4D2、字#181A1A、副#C43B2E、点#D5A72F；浅纸底中深色书法，彩纹控制在主场边侧。
- 深色明字：底#181A1A、字#EFE4D2、副#C43B2E、点#D5A72F；深底托出亮字，纹样以细线和局部彩色浮现。
- 主色成境：底#C43B2E、字#EFE4D2、副#181A1A、点#D5A72F；工艺色作主底，主字保持清楚明度差；金色只作平薄印色，不出现镜头炫光。

底材：淡纸或浅绢上有低对比细纹，清楚字腔不积污渍；深绢或深色印纸，材质同色可见，主字区域平静；所选主色的平面印色与细织理，色区有层次不叠万能噪点。

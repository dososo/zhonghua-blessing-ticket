# 中华民族祝福票3.0.0

## 内容

本版固定作者认可的「山河锦意」古典民艺印刷体系。Skill自包含55民族设计记录、13种字骨、25种工艺配方、12种文字布局、8种画面构图及实际内置参考图。

图案与准确中文主标题原生一体生成。支持独立3:4卡、目标1080×2336长票，以及十卡总览；最后一辑为五卡。目标像素与实际输出分别记录。

仓库介绍收录已确认的v3原生总览及作者授权的六辑展示图。它们与Skill内置视觉基准的用途分开，详见[素材说明](../ASSETS.md)。

## 安装

从[Release](https://github.com/dososo/zhonghua-blessing-ticket/releases/latest)下载完整ZIP，解压后执行`bash scripts/install_codex_macos.sh`。已有同名安装使用`--replace`，旧目录先备份。安装器需要Python3.9或更新；手动复制完整Skill目录不需要Python。

## 验证与附件

可运行单元测试、数据校验与发布检查，具体命令见[README](../README.md)。已完成一次真实参考输入与原生总览生成，标题经过视觉核对并获得作者效果确认；这不等于55民族文化专家验收。见[验证边界](验证边界.md)。

Release提供`zhbt-v3.0.0.zip`、`SHA256SUMS.txt`与`build-manifest.json`。公开包不含本地过程记录、原始日志、用户历史、私有参考、凭证或字体。仓库公开不等于上架官方插件目录。

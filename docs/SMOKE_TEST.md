# Codex桌面真实闭环

先安装本Skill，打开新会话，检查能读取本版本SKILL.md和assets/approved-overview.png。

第一次只生成一张：

```text
使用 $zhonghua-blessing-ticket：苗族，大吉大利，3:4。
先打开技能内的已确认审美基准，生成时实际附加参考图。图与主字直接生成。无年份、无民族主标题、不增加随机小字。完成后打开图逐字检查，报告实际像素。只允许一次初稿和最多两次局部修复。
```

记录是否真的读取参考文件、是否有真实图像调用、输出是否存在、原生输出尺寸、标题转录、文化锚点与明显偏离。没有证据的项目写未验证。

第二次再生成十卡总览：

```text
使用 $zhonghua-blessing-ticket：生成第一辑01—10的十卡总览，以内置基准保持绘画和印刷气质，每卡使用自己的文化记录。图与主标题一体生成，按卡位逐字审查。总览为本次交付，不要求拆分单张高清，不将单格声称为1080×2336。
```

通过后在reports/local-smoke.json自行记录实际宿主版本、工具名称、相对输出路径、图像哈希、参考图是否真正传入、标题转录和人工结论。样张只能在用户确认后加入公开仓库；不上传日志中的账号或凭证。

# 28 柯尔克孜族｜毡房天窗

文化范围：新疆柯尔克孜族毡艺生活。

主锚点：毡绣曲线与毡房天窗。
辅助元素：库姆孜、山地、马具局部。
默认祝福：鸿运当头。用户输入优先，不擅自改词或简繁。
其他可选祝福：吉星高照、万事亨通、平安喜乐。

## 基准方案

字骨：隶意票券。主工艺：织毯绒面。
构图：圆纹回响。
标题布局：开放竖写；字数不适合时选择合法布局，不能改动原词来适配。

## 同一审美中的变化

字骨候选：隶意票券、粗笔榜书、清俊行书、金石碑意。
主工艺候选：织毯绒面、刺绣针脚、纸本套印、纸本墨色。
构图候选：圆纹回响、锦纹护字、花叶成境。
字图关系：主字完整可读，所选工艺的线条在标题外缘呼应；不把纹样替换为用户未输入的字。

色谱按创作分工，不把一种颜色定义为某民族唯一的固有颜色：
- 浅纸深字：底#F0E5D1、字#1C2630、副#B64A3C、点#1C2630；浅纸底中深色书法，彩纹控制在主场边侧。
- 深色明字：底#1C2630、字#F0E5D1、副#B64A3C、点#1C2630；深底托出亮字，纹样以细线和局部彩色浮现。
- 主色成境：底#B64A3C、字#F0E5D1、副#1C2630、点#1C2630；工艺色作主底，主字保持清楚明度差；金色只作平薄印色，不出现镜头炫光。

底材：淡纸或浅绢上有低对比细纹，清楚字腔不积污渍；深绢或深色印纸，材质同色可见，主字区域平静；所选主色的平面印色与细织理，色区有层次不叠万能噪点。

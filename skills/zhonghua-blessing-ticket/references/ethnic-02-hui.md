# 02 回族｜砖雕清雅

文化范围：宁夏或河湟等具体社区，需选定一处。

主锚点：木格窗与砖雕花草。
辅助元素：盖碗、院落、朴素植物纹。
默认祝福：平安喜乐。用户输入优先，不擅自改词或简繁。
其他可选祝福：福至心安、和顺美满、家和业兴。

## 基准方案

字骨：清俊行书。主工艺：木刻版画。
构图：门庭纳福。
标题布局：开放竖写；字数不适合时选择合法布局，不能改动原词来适配。

## 同一审美中的变化

字骨候选：清俊行书、隶意票券、粗笔榜书、金石碑意。
主工艺候选：木刻版画、石刻碑铭、纸本套印、纸本墨色。
构图候选：门庭纳福、锦纹护字、花叶成境。
字图关系：主字完整可读，所选工艺的线条在标题外缘呼应；不把纹样替换为用户未输入的字。

色谱按创作分工，不把一种颜色定义为某民族唯一的固有颜色：
- 浅纸深字：底#F2E9D3、字#175F60、副#3A9593、点#B99147；浅纸底中深色书法，彩纹控制在主场边侧。
- 深色明字：底#175F60、字#F2E9D3、副#3A9593、点#B99147；深底托出亮字，纹样以细线和局部彩色浮现。
- 主色成境：底#3A9593、字#F2E9D3、副#175F60、点#B99147；工艺色作主底，主字保持清楚明度差；金色只作平薄印色，不出现镜头炫光。

底材：淡纸或浅绢上有低对比细纹，清楚字腔不积污渍；深绢或深色印纸，材质同色可见，主字区域平静；所选主色的平面印色与细织理，色区有层次不叠万能噪点。

## 文化核查

生活工艺并非民族独占；不得用任意中东清真寺替代中国地方建筑。
当前记录是有范围的设计路线，不宣称覆盖该民族全部支系、审美或信仰。；具体纹样、器物形制、服饰必须另找实物或社区资料，不从人物面貌推断民族。

研究关键词：回族 石刻碑铭 非遗 博物馆；回族 木格窗与砖雕花草 实物。
证据状态：研究索引＋保守创作锚点；未做全体社区专家鉴定。名录仅核对民族名称；工艺与地区为待核验研究关键词，不能用名录充当专属纹样证据。

# 05 苗族｜银光蜡影

文化范围：贵州黔东南具体苗族工艺支系。

主锚点：银冠的薄片錾花与垂饰。
辅助元素：蝴蝶纹、靛蓝染织、绣片局部。
默认祝福：岁岁如意。用户输入优先，不擅自改词或简繁。
其他可选祝福：大吉大利、福气满满、吉星高照、锦绣安康。

## 基准方案

字骨：金石碑意。主工艺：银饰錾刻。
构图：锦纹护字。
标题布局：双列对开；字数不适合时选择合法布局，不能改动原词来适配。

## 同一审美中的变化

字骨候选：金石碑意、粗笔榜书、清俊行书、隶意票券。
主工艺候选：银饰錾刻、刺绣针脚、蜡防染、纸本套印、纸本墨色。
构图候选：锦纹护字、山河承字、花叶成境。
字图关系：主字完整可读，所选工艺的线条在标题外缘呼应；不把纹样替换为用户未输入的字。

色谱按创作分工，不把一种颜色定义为某民族唯一的固有颜色：
- 浅纸深字：底#EAE4D7、字#0D243F、副#346274、点#AA436C；浅纸底中深色书法，彩纹控制在主场边侧。
- 深色明字：底#0D243F、字#EAE4D7、副#346274、点#AA436C；深底托出亮字，纹样以细线和局部彩色浮现。
- 主色成境：底#346274、字#EAE4D7、副#0D243F、点#AA436C；工艺色作主底，主字保持清楚明度差；金色只作平薄印色，不出现镜头炫光。

底材：淡纸或浅绢上有低对比细纹，清楚字腔不积污渍；深绢或深色印纸，材质同色可见，主字区域平静；所选主色的平面印色与细织理，色区有层次不叠万能噪点。

## 文化核查

苗绣与银冠均有支系差异；蝴蝶寓意不作所有苗族统一信仰断言。
当前记录是有范围的设计路线，不宣称覆盖该民族全部支系、审美或信仰。；具体纹样、器物形制、服饰必须另找实物或社区资料，不从人物面貌推断民族。

研究关键词：苗族 银饰錾刻 非遗 博物馆；苗族 银冠的薄片錾花与垂饰 实物。

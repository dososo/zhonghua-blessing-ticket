# 32 羌族｜石碉云路

文化范围：四川岷江羌族社区。

主锚点：羌碉石构与羌绣。
辅助元素：云云鞋纹、山花、山谷。
默认祝福：吉祥如意。用户输入优先，不擅自改词或简繁。
其他可选祝福：福佑安康、步步高升、山河无恙。

## 基准方案

字骨：魏碑意。主工艺：石刻碑铭。
构图：门庭纳福。
标题布局：开放竖写；字数不适合时选择合法布局，不能改动原词来适配。

## 同一审美中的变化

字骨候选：魏碑意、粗笔榜书、清俊行书、隶意票券、金石碑意。
主工艺候选：石刻碑铭、刺绣针脚、纸本套印、纸本墨色。
构图候选：门庭纳福、锦纹护字、花叶成境。
字图关系：主字完整可读，所选工艺的线条在标题外缘呼应；不把纹样替换为用户未输入的字。

色谱按创作分工，不把一种颜色定义为某民族唯一的固有颜色：
- 浅纸深字：底#E8E4DA、字#1B2023、副#787B78、点#E8E4DA；浅纸底中深色书法，彩纹控制在主场边侧。
- 深色明字：底#1B2023、字#E8E4DA、副#787B78、点#E8E4DA；深底托出亮字，纹样以细线和局部彩色浮现。
- 主色成境：底#787B78、字#E8E4DA、副#1B2023、点#E8E4DA；工艺色作主底，主字保持清楚明度差；金色只作平薄印色，不出现镜头炫光。

底材：淡纸或浅绢上有低对比细纹，清楚字腔不积污渍；深绢或深色印纸，材质同色可见，主字区域平静；所选主色的平面印色与细织理，色区有层次不叠万能噪点。

## 文化核查

白石与仪式相关需谨慎；不默认藏式经幡；碉楼不可画成欧式城堡。
当前记录是有范围的设计路线，不宣称覆盖该民族全部支系、审美或信仰。；具体纹样、器物形制、服饰必须另找实物或社区资料，不从人物面貌推断民族。

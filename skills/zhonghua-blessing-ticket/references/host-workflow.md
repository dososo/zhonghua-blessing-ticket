# 宿主执行：Skill不等于图像模型

本Skill是自包含说明、数据与辅助脚本。没有后台服务、账号系统、付费API强制依赖或自动遥测。原生图像生成需宿主提供。

本次查阅的OpenAI官方图像文档说明可在交互会话中使用自然语言或`$imagegen`生成图像，并使用已有图片作为视觉指导；文档也提醒对文字内容、样式和位置写清楚。实际工具名与参数仍以运行时可用说明为准。

## 必须实际执行的闭环

读取基准图和本族记录 → 编译具体方案 → 打开并附加参考图到生图调用 → 直接生成完整图文 → 打开实际输出检查 → 有限修复 → 保存真实回执。

只读参考路径、只写计划或只跑命令行，都不能说完成了生图。

脚本不注入隐藏工具参数，不内置API密钥，不尝试从浏览器、钥匙串或环境文件提取凭证。使用原生工具的费用和配额由宿主说明。

## 画布两条路

**总览直出**：用户接受一张十卡总览时，一次原生图像调用生成整张图，按照行列映射检查。可作为总览交付。该图的单格尺寸可能较小，不能假称独立高清。

**独立卡拼版**：用户需要十张独立卡时，逐张生成，再确定性拼版。Pillow仅在这一可选步骤使用，不绘制替代艺术，不覆盖主标题。

总览和独立卡共享数据与基准，交付语义不同。不要未经用户要求把一张总览改成十次生图。

## 缺能力时

清楚说明当前会话没有原生生图或不能附加参考图。保存具体方案供用户换到支持环境继续；不能声称已获得与基准相同的结果。不要擅自安装新服务、切换API或索要密钥。

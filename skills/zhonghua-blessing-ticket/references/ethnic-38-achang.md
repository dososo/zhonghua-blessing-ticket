# 38 阿昌族｜钢锋茶影

文化范围：云南陇川户撒等阿昌族工艺。

主锚点：户撒刀鞘与金属锻纹。
辅助元素：织物、工坊木架、山地。
默认祝福：锦绣安泰。用户输入优先，不擅自改词或简繁。
其他可选祝福：事业顺心、平安顺遂、茶香福来。

## 基准方案

字骨：魏碑意。主工艺：银饰錾刻。
构图：器物引势。
标题布局：开放竖写；字数不适合时选择合法布局，不能改动原词来适配。

## 同一审美中的变化

字骨候选：魏碑意、粗笔榜书、清俊行书、隶意票券、金石碑意。
主工艺候选：银饰錾刻、木刻版画、纸本套印、纸本墨色。
构图候选：器物引势、锦纹护字、花叶成境。
字图关系：主字完整可读，所选工艺的线条在标题外缘呼应；不把纹样替换为用户未输入的字。

色谱按创作分工，不把一种颜色定义为某民族唯一的固有颜色：
- 浅纸深字：底#EEE2CF、字#17191B、副#4D6470、点#C25A36；浅纸底中深色书法，彩纹控制在主场边侧。
- 深色明字：底#17191B、字#EEE2CF、副#4D6470、点#C25A36；深底托出亮字，纹样以细线和局部彩色浮现。
- 主色成境：底#4D6470、字#EEE2CF、副#17191B、点#C25A36；工艺色作主底，主字保持清楚明度差；金色只作平薄印色，不出现镜头炫光。

底材：淡纸或浅绢上有低对比细纹，清楚字腔不积污渍；深绢或深色印纸，材质同色可见，主字区域平静；所选主色的平面印色与细织理，色区有层次不叠万能噪点。

## 文化核查

呈现手工制作不表现攻击；刀形有依据；不用侗族风雨桥替代民居。
当前记录是有范围的设计路线，不宣称覆盖该民族全部支系、审美或信仰。；具体纹样、器物形制、服饰必须另找实物或社区资料，不从人物面貌推断民族。

研究关键词：阿昌族 银饰錾刻 非遗 博物馆；阿昌族 户撒刀鞘与金属锻纹 实物。

# 39 普米族｜火塘笙烟

文化范围：滇川普米族生活。

主锚点：羊毛织物与火塘。
辅助元素：木器、葫芦笙、山林。
默认祝福：平安顺遂。用户输入优先，不擅自改词或简繁。
其他可选祝福：岁岁安暖、福聚人间、喜乐长安。

## 基准方案

字骨：民间手写。主工艺：织毯绒面。
构图：花叶成境。
标题布局：开放竖写；字数不适合时选择合法布局，不能改动原词来适配。

## 同一审美中的变化

字骨候选：民间手写、粗笔榜书、清俊行书、隶意票券、金石碑意。
主工艺候选：织毯绒面、棉线织染、纸本套印、纸本墨色。
构图候选：花叶成境、锦纹护字、器物引势。
字图关系：主字完整可读，所选工艺的线条在标题外缘呼应；不把纹样替换为用户未输入的字。

色谱按创作分工，不把一种颜色定义为某民族唯一的固有颜色：
- 浅纸深字：底#E7D9C5、字#3C2D27、副#E7D9C5、点#8B3C3A；浅纸底中深色书法，彩纹控制在主场边侧。
- 深色明字：底#3C2D27、字#E7D9C5、副#E7D9C5、点#8B3C3A；深底托出亮字，纹样以细线和局部彩色浮现。
- 主色成境：底#E7D9C5、字#3C2D27、副#3C2D27、点#8B3C3A；工艺色作主底，主字保持清楚明度差；金色只作平薄印色，不出现镜头炫光。

底材：淡纸或浅绢上有低对比细纹，清楚字腔不积污渍；深绢或深色印纸，材质同色可见，主字区域平静；所选主色的平面印色与细织理，色区有层次不叠万能噪点。

## 文化核查

服饰和信仰内部多样；不全部处理成藏族寺院题材。
当前记录是有范围的设计路线，不宣称覆盖该民族全部支系、审美或信仰。；具体纹样、器物形制、服饰必须另找实物或社区资料，不从人物面貌推断民族。

研究关键词：普米族 织毯绒面 非遗 博物馆；普米族 羊毛织物与火塘 实物。
证据状态：研究索引＋保守创作锚点；未做全体社区专家鉴定。名录仅核对民族名称；工艺与地区为待核验研究关键词，不能用名录充当专属纹样证据。

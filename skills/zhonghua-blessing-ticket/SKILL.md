# 中华民族祝福票

## 先确定当前任务

用户只需「民族＋祝福词」，如「苗族，大吉大利」。默认单张3:4；「长票／留白版」对应目标1080×2336；「第一辑／前10个／十卡总览」走总览。缺民族或祝福时只问缺少项；总览已有默认词，不多问参数。用户说「继续」时接续本会话上次完成的批次，不根据别的对话猜进度。

优先遵从当前用户要求。这里提供同一审美体系中的变化，不夸称“世界第一”“绝对不重复”或“零错字”。

## 本次必须使用的审美基准

先读取 `references/visual-contract.md`，打开 `assets/approved-overview.png`。它是作者已认可的生成式十卡总览，定义古典民艺印刷、山河层次、精细纹饰、明显书法和冷暖底色的组合。

生成工具支持参考图时，实际传入该图片，而不只在提示词里写一个路径。读取图片与把图片传入模型是两件事。单卡可再读对应 `assets/reference-cell-XX.png`，只借笔势与组织，主标题必须换成用户准确输入。它们是局部风格参照，不能被放大充当新成品。

不复制参考中的潜在文化错误。民族标签、书法、人物服饰、宗教建筑均不是文化真实性证据；遇到具体支系、神圣符号、乐器或服饰，需要可信实物来源。

## 最短可执行流程

1. **识别模式**：单张、总览、独立卡拼版、修复或审查。默认不跑额外批量。
2. **读取文化记录**：先读 `references/ethnic-index.md`，再仅阅读对应民族文件。规则或字体需要时读 `references/typography.md`，不要把55份记录全部塞进单张提示词。
3. **确认工具**：读取当前宿主的图像工具或已安装 `$imagegen` 的实际说明。优先使用宿主原生生图，不要求用户提供API密钥，不擅自切换付费API。若没有图像工具，停止在“可执行方案”，说明缺少能力；不要用SVG占位、代码绘图或提示词文本冒称成图。
4. **编译设计**：有Python时运行下文脚本；否则按同样数据规则手动形成设计简报。文字、民族锚点、构图、色彩必须具体。不要把九层所有词一次堆满提示词。
5. **直接生图**：标题、纹样、山河、工艺效果一起生成。默认绝不生成无字底图再叠主标题。参考图是风格，用户文本是内容，文化来源是形制，三者分清优先级。
6. **看图验收**：逐字读标题；比对参考的绘画语言、细节密度和色调；检查民族形制、串用、文字遮挡和尺寸。检索无关文化图不能替代这次成图检查。
7. **有限修复**：单张一次初稿后最多两次定向编辑；总览一次初稿后最多一次定向编辑。只改具体问题，保留成功的视觉关系。达到上限说明哪个问题尚未解决，不无限重试，不自动扩展需求。
8. **保存并交付**：保留真实文件、实际像素、工具回执、方案指纹和审查记录。只链接实际存在的成图。主标题转录、文化确认和最终审美由宿主视觉或人判断，离线脚本不会自动完成这些判断。

## 运行脚本

以下命令中的 `<技能目录>` 是本文件所在目录，必须替换为当前实际路径。使用运行目录的 `outputs/`，不要将用户历史和图片写回安装目录。

```bash
python3 "<技能目录>/scripts/plan.py" single --ethnic 苗族 --blessing 大吉大利 --format 3:4 --out outputs/miao.json --history outputs/history-v3.json
```

生成的 JSON 与 `.prompt.txt` **都只是设计输入**。把提示词连同已打开的参考图交给原生图像工具才会出图。

```bash
python3 "<技能目录>/scripts/plan.py" canvas --start 1 --count 10 --out outputs/canvas-01.json
```

`canvas` 默认允许直接生成一张5×2总览，与已认可的交付方式一致。最后51—55为5×1。用户选择无标签时加 `--no-labels`。默认小民族名只是目录标签；独立卡默认不显示民族名。不要额外写年份和日期。

要求每张独立高清文件时，改用 `--strategy assembled --format long`，逐张生图与审查，再用 `scripts/assemble.py` 无损拼版。不得将低分辨率总览裁切放大为“原生高清”。

```bash
python3 "<技能目录>/scripts/plan.py" receipt --plan outputs/miao.json --image outputs/miao.png --transcription 大吉大利 --note "实际视觉检查记录" --out outputs/miao.receipt.json
```

`receipt`记录真实尺寸和提交者转录，并不自己识字。主标题原生生成分辨率只能依据真实工具回执证明。

## 图文一体的硬约束

- 用户输入的祝福不得自动改成更好听的另一句；繁简体也不擅自转换。
- 先按真实字数筛选字面构图：二字才能使用两字巨幅、三字才能用三字错落、四字才能用四字两行。更长词要有清楚的阅读路径。
- 文字配方 = 字骨＋笔势＋一种主工艺＋文字布局＋主字明度＋有限边缘效果＋一处字图关系。更多参数是可选精调，不是必选特效。
- 拟银、拟绣、木印、哑金体现于成图内；禁止默认文字贴片、三维挤出和金属游戏字。
- 飞白不吞关键笔画，阴刻不破坏偏旁，字图相交不挡住最关键字腔。
- 小字默认关闭；用户需要时使用预先确定的短中文。印章采用纯几何或标题内一个字；不制造伪篆文、伪民族文字和随机英文。
- 图面无年份、日期和生肖纪年；「年年有余」「岁岁平安」等普通祝福允许。

## 风格锁定与合理变化

保持：古典民艺平面印刷、清楚的中文主视觉、装饰性山河、细密工艺纹、冷暖有序、祝福温度。
变化：深浅底色、具体工艺、书法骨架、字序布局、器物尺度、装饰的疏密位置。不要把每张变成完全不同的画种，也不要同一中央牌匾换民族标签。

金属高反射、大片裂纹、极端破损、霓虹、高定产品摄影和电影剧照都不是本版默认方向。用户已经认可的总览比旧版探索建议优先。

## 文化核查

查 `references/culture-policy.md` 与对应民族记录。民族内部有地区和支系差异；一个锚点是一条设计路径，不代表全体成员。宗教身份不能从民族名自动推断；不得借邻近民族或外国服饰、文字、地标填空。

优先普通生活、手工、材料、地方景观。无法核验的专用纹样不生成，不用形似乱码的装饰替代。涉及高山族内部具体群体时先确定群体，再引用其符号，不能将某群体的舟或人像纹泛化。

## 必须如实说明的边界

安装Skill不安装图像模型；图像可用性由宿主、版本、计划与权限决定。编译不是生图。新指纹不是审美独特性证明。精准文字指令不是零错字保证。总览是有效成品类型，但不是每卡独立高清文件。参考图是既有认可样张，不是本版新流程已通过55族端到端验收的证据。
